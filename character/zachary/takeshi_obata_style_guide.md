## Key Style Elements
1. **Clean line art** - Sharp, clean black lines for outlines
2. **Soft shading** - Gentle gradients for depth
3. **Detailed eyes** - Expressive, detailed eye illustrations
4. **Professional manga** - High-quality illustration style

## Notes
- Always use Takeshi Obata (Death Note manga) style
- Maintain consistent character design across all panels
- Ensure dialog bubbles are properly positioned (HTML overlay, not embedded in image)
- Keep background consistent with scene (rainy city evening)
